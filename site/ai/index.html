AI assistants

Change your website by asking for it.

Every Vibe CMS site comes with its own MCP server, the standard way AI assistants use tools. Connect your assistant once and say what you want changed.

  • ChatGPT
  • Claude and Claude Code
  • Grok through the xAI API
  • Any MCP client

Safe by design

The assistant drafts. A person decides.

  • Drafts by default. A connection saves changes as drafts. People review them in the editor and press Publish.
  • Publishing is opt-in. Give a connection the publish permission only if you want it, and the assistant is told to ask you first.
  • Same rules as people. Saved HTML is cleaned of scripts, shared parts need the editor role, and every publish lands in History.
  • One key per assistant. Each shows when it was last used and can be turned off in a click.

Rewrite the About page intro so it sounds warmer, and fix the title for Google.

get_page /about/
update_region /about/ main
set_page_settings /about/

I rewrote the first two paragraphs and set the title to “About Juniper Café: a neighbourhood bakery on Main Street” (57 characters). Both are drafts. Have a look at /about/?edit, then tell me if you want it published.

Tools

What the assistant can do

list_pages

Every page on the site and which ones have unpublished changes.

get_page

A page’s title, description and editable regions as they stand, drafts included.

replace_text

Find exact text on a page and replace it. The safest edit: it can’t touch anything else.

update_region

Rewrite a whole region, for new sections or a fresh page, keeping the site’s own classes.

set_page_settings

Page title and search description, with length guidance for Google.

publish

Make drafts live, for one page or all of them, when the connection is allowed to.

Also: list_drafts, discard_drafts and get_history.

Connect

Set up in two minutes

An admin opens the editor, goes to Editors › AI assistants, names the assistant and copies its private address. Developers can run vibecms connect ChatGPT instead.

ChatGPT

Settings › Apps › Advanced settings: turn on developer mode, then create an app with the address as its MCP server URL and no authentication. Pick it from the + menu in a chat.

Claude

On claude.ai or the desktop app: Settings › Connectors › Add custom connector, and paste the address. In Claude Code: claude mcp add --transport http mysite <address>.

Grok

Through the xAI API, add the address as a remote MCP tool. Grok’s app doesn’t take custom connectors yet; we’ll list Vibe CMS there when it does.
