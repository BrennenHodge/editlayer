AI assistants

Change your website by asking for it.

Every Editlayer site comes with its own MCP server, the standard way AI assistants use tools. Connect your assistant once and say what you want changed.

  • ChatGPT
  • Claude and Claude Code
  • Grok through the xAI API
  • Any MCP client

Safe by design

The assistant drafts. A person decides.

  • Drafts by default. A connection saves changes as drafts. People review them in the editor and press Publish.
  • Publishing is opt-in. Give a connection the publish permission only if you want it, and the assistant is told to ask you first.
  • Same rules as people. Saved HTML is cleaned of scripts, shared parts need the editor role, and every publish lands in History.
  • One key per assistant. Each shows when it was last used and can be turned off in a click.

Tools

What the assistant can do

list_pages

Every page on the site and which ones have unpublished changes.

get_page

A page’s title, description and editable regions as they stand, drafts included.

replace_text

Find exact text on a page and replace it. The safest edit: it can’t touch anything else.

update_region

Rewrite a whole region, for new sections or a fresh page, keeping the site’s own classes.

set_page_settings

Page title and search description, with length guidance for Google.

publish

Make drafts live, for one page or all of them, when the connection is allowed to.

Also: list_drafts, discard_drafts and get_history.

Connect

Set up in two minutes

Add Editlayer to your assistant with one address, https://mcp.editlayer.co/mcp. It asks for your website, you sign in to it as usual and choose drafts only or drafts and publishing. Only an admin of the site can approve.

ChatGPT

Open chatgpt.com/plugins, choose + › Add custom MCP server, paste the address and pick OAuth. Sign in to your site when asked, then type @Editlayer in a chat.

Claude

On claude.ai or the desktop app: Settings › Connectors › Add custom connector, paste the address and sign in to your site. In Claude Code: claude mcp add --transport http editlayer https://mcp.editlayer.co/mcp.

Grok

Through the xAI API, add a site’s private address (below) as a remote MCP tool. Grok’s app doesn’t take custom connectors yet; we’ll list Editlayer there when it does.

A private address for one site, for Grok, scripts or any MCP client without sign-in: an admin opens the editor, goes to Editors › AI assistants and names the assistant. Developers can run editlayer connect Grok. Either way, an admin can turn a connection off there at any time.
