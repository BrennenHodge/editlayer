Features

The whole site, editable where it lives.

Editors never see a dashboard of fields. They see their own website, and everything on it answers to a click. Here is all of it.

  • Works on phones and desktops
  • Plain-language for non-technical staff
  • Undo for everything

On the page

Words, pictures and sections

Text

  • Click any text and type over it
  • Enter for a new paragraph or list item
  • Bold, italic and links (Ctrl+B, I, K)
  • Paste is always plain text, so no stray fonts
  • Headings and buttons stay plain on purpose

Media

  • Replace a photo by upload or from the library
  • Resized and converted to WebP in the browser
  • Alt text in the same dialog
  • Focal point, so crops keep the subject
  • Background images, PDFs and video embeds

Sections

  • Move, duplicate, hide or delete a section
  • Ready-made blocks designed for the site
  • Shared sections: edit once, used on many pages
  • Copy a section from any other page
  • Section settings such as background

Menus, header and footer

  • Edit the menu once for the whole site
  • Add, rename, reorder and remove links
  • The current page stays marked on every page
  • Footer text and links site-wide

Pages

  • New pages from the site’s own layouts
  • Page title and description with a Google preview
  • Phone, tablet and desktop preview
  • New pages join the sitemap when published

Site styles

  • Brand colours, fonts, weights and corners
  • Only the settings the developer allows
  • Readability checks on every colour pair
  • Saved as a draft like any other change

Publishing

Safe for a whole team

Drafts and publishing

Changes autosave as drafts only editors can see. Publish makes the page live, together with the site-wide header and footer.

Roles and approval

Authors edit and send pages for review. Editors approve and publish. Admins also invite people, by link or by email.

Scheduling and previews

Publish at a set time, or share a preview link with someone who has no account. Links expire after seven days.

History and restore

Every publish is kept. Restore any version as a draft, discard drafts, or reset a page to the developer’s version.

Checks before publishing

Pictures with no description, links that go nowhere, skipped headings, hard-to-read text and overlong titles are flagged before anything goes live.

Edit from a phone

The editor works in a phone’s browser too, so a quick fix on the go takes a minute.

Built in

The extras most sites end up needing

Form inbox

Site forms send to an inbox in the editor, with spam filtering, search, email alerts and a spreadsheet export. No form service needed.

Writing help

Fix spelling, or make a paragraph shorter, clearer, friendlier or more formal, in place. Find and replace across the whole site.

AI assistants

Connect ChatGPT or Claude through the site’s MCP endpoint and edit by asking. Developers can use Grok through the xAI API. How it works.
