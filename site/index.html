How it works

Build it with AI. Hand it over.

Editlayer adds editing to the site you already have. Nothing is rebuilt, and the design can’t be broken by an edit.

  1. 01

    Build the site your way

    Claude Code, Cursor, a static generator or plain HTML. Any static site with a <main> works.

  2. 02

    Add Editlayer in one step

    Install the plugin and ask Claude Code to make the site editable. It sets up the database, storage and the editor on Cloudflare.

    /editlayer:editlayer

  3. 03

    Send the owner a link

    They choose a password, press Edit page on their own site and start typing. Drafts autosave; Publish makes them live.

How AI editing works

Our Saturday hours are changing to 9 to 1. Update the site.

list_pages · get_page /visit/
replace_text “8am – 2pm” → “9am – 1pm”

Done. Saturday now reads 9am – 1pm on the Visit page and in the footer. It’s saved as a draft: review it at junipercafe.example/visit/?edit. Want me to publish it?

Yes, publish.

publish /visit/

Live now. You can roll it back from History in the editor.

For developers

Your code stays the source of truth.

No framework to adopt, no content model to design, no rewrite. Editlayer runs in front of your static site as a Cloudflare Worker and swaps edited regions into the HTML as it streams.

  • Edits are stored in D1, images in R2, on your own Cloudflare account
  • Untouched pages are served byte for byte; if Editlayer errors, the static page is served
  • Rebuild any time: editlayer status shows what editors changed

Questions

Good to know

What kind of sites does it work with?

Static sites: plain HTML, or the output of a static build (Astro, Eleventy, Hugo, Vite and similar), hosted as a Cloudflare Worker. Each page needs a <main> element and the site needs a sitemap. Server-rendered apps aren’t supported.

Do I need a Cloudflare account?

Yes. The site, its edits (D1) and its images (R2) live in your Cloudflare account, so you own the data. Small sites usually fit Cloudflare’s free tier.

What happens when I rebuild the site?

Rebuild and deploy as usual. Pages nobody edited update straight away. If you change a region an editor also changed, their version keeps showing and the editor offers “keep mine” or “use the developer’s version”.

Can ChatGPT really change my website?

Only if an admin connects it, and only as drafts unless you allow publishing. It works through the site’s MCP endpoint with its own key, which you can turn off any time. Every change shows up in the editor and in History.

Is it secure?

Passwords are hashed with PBKDF2, sessions are HttpOnly cookies, accounts lock after repeated failed sign-ins, every change needs a same-origin request, and saved HTML is stripped of scripts and event handlers.

Is this site built with it?

Yes. Everything you’re reading is edited in Editlayer. Even the early-access form sends to the Editlayer inbox.
